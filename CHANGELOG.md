# Изменения

## 2.0 — в разработке

Библиотека переписана с нуля.

- Модель таблицы по образцу HTML: шапка, тела, подвал, заголовок, колонки, объединение ячеек.
- Каскад стилей «таблица → секция → колонка → строка → правила → ячейка» и условные правила (`Match`).
- Раскладка как в браузере: алгоритмы `table-layout: auto/fixed`, ширины в пикселях и процентах,
  выравнивание по базовой линии, схлопывание рамок с разрешением конфликтов по правилам CSS.
- Оформление: 10 стилей рамок, скругления, тени, контур, прозрачность, градиенты (линейные, радиальные,
  конические, повторяющиеся), фоновые изображения.
- Текстовый движок: форматированный текст, бейджи, изображения в тексте, индексы, линии оформления,
  тени и обводка текста, переносы по правилам Unicode, мягкие переносы, многоточие, ограничение строк,
  запасные шрифты.
- Построение таблицы из коллекции объектов, темы оформления.
- Результат с геометрией ячеек, вывод на произвольную `Graphics2D`, масштабирование для HiDPI.
- Документация на русском с примерами, генерируемыми из кода.
