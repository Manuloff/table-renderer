# Документация table-renderer

Подробное описание Java-библиотеки для отрисовки таблиц в изображение.

## Содержание

1. [Архитектура и основные понятия](architecture.md) — `Table`, ячейки с `rowspan` / `colspan`, строки, колонки, `RenderedTable`, иерархия стилей.
2. [Стили](styles.md) — `TableStyle`, `TextStyle`, рамки, выравнивание, отступы, качество рендеринга и значения по умолчанию.
3. [Примеры](examples.md) — объединение ячеек, выравнивание, рамки, фиксированные размеры и другие сценарии из реального API.

Краткий обзор и подключение библиотеки — в [README](../README.md) в корне репозитория.

## Пакеты

| Пакет | Назначение |
| --- | --- |
| `me.manuloff.lib.table.renderer` | Модель таблицы и рендерер |
| `me.manuloff.lib.table.renderer.style` | Стили оформления |

Точка входа: создать `Table`, заполнить через `getCell` / `getRow` / `getColumn`, вызвать `render()`.
